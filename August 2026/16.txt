1.  Normally our java code runs on a main single thread until we create new thread , runnale or callable 
creates a task first then we either call start or run() methoda on it if you call run that task runs on
 a the main thread only, in during call of start it creates new thread and then the execution of that task

And the Runnable is simply the work/task that the thread executes.

That's the cleanest mental model:

Runnable = what to do
Thread = who does it
start() = start that worker thread
run() = just execute the task like a normal method


class MyTask implements Runnable {

    @Override
    public void run() {
        System.out.println(
            "Task is running on: " +
            Thread.currentThread().getName()
        );
    }
}

public class Main {

    public static void main(String[] args) {

        System.out.println(
            "Main is running on: " +
            Thread.currentThread().getName()
        );

        // Creating the TASK
        MyTask task = new MyTask();


        // -------------------------
        // CASE 1: Calling run()
        // -------------------------

        System.out.println("Calling run()...");

        task.run();


        // -------------------------
        // CASE 2: Calling start()
        // -------------------------

        System.out.println("Calling start()...");

        Thread thread = new Thread(task);

        thread.start();
    }
}
